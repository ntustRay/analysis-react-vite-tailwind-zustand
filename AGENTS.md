# Working on the weather and population dashboard

- Weather state is in `src/stores/useWeatherStore.js`. Taiwan population data is in `src/data/populationData.js`. Keep API state and static data in those existing locations.
- Run `npm ci`, `npm run lint`, and `npm run build`. Use `npm run dev` to exercise both dashboard routes.
- Keep the Vite base path and React Router basename aligned with the GitHub Pages project path when changing navigation.
